## v16 (2026-11-24) — 시작 화면·게임오버 디자인 변경

**화면 개선**
- 시작 화면을 새로 디자인했습니다. 하늘 배경, 타이틀 로고, 완두콩 캐릭터, 완두콩 모양 기록 배지(최고 기록·오늘 기록·연속 출석)를 넣었습니다.
- '오늘 기록'(오늘 최고 층수)을 새로 저장해 보여 줍니다.
- 게임오버 팝업을 새로 디자인했습니다. 입체 버튼과 어두운 배경을 넣었고, 코인 받는 판 표시를 정리했습니다.
- 버튼과 문구에 둥근 글씨체(주아체, OFL)를 적용했습니다.
- 쌓을 때 뜨는 문구('딱!', '모자라!', '넘쳤다!')도 주아체로 바꿨습니다.

게임 규칙, 광고·결제, 권한은 바뀌지 않았습니다.

## v14 (2026-11-23) — 앱인토스 출시

콘솔에 v8~v14로 나눠 올린 수정을 모두 포함해요.

**1. 난이도 조정**
- '딱' 판정 범위를 층에 따라 단계적으로 좁혔습니다. 0층 ±9%에서 시작해 20층마다 줄어들고, 120층부터 ±2%로 고정됩니다.
- 막대가 자라는 기본 속도를 높였습니다. 시작 140px/s, 층마다 +1.6, 최대 320px/s입니다.
- '딱'을 연속으로 성공하면 막대 속도가 8%씩 빨라집니다. 최대 2배까지 오르고, 실수하면 원래 속도로 돌아옵니다.
- 연속 '딱' 성공 시 탑 폭이 다시 넓어지던 기능을 없앴습니다.

**2. 조작 개선**
- 화면을 누르고 있으면 막대가 아래층의 1.7배까지 늘어났다가 다시 줄어드는 동작을 반복합니다.
- 이전처럼 1.9배에서 자동으로 놓이지 않아, 원하는 폭에서 손을 뗄 수 있습니다.

**3. 버그 수정**
- 화면을 짧게 연속으로 누르기만 해도 높은 층까지 올라가던 문제를 수정했습니다.
- 게임 오버 기준 폭을 16px에서 36px(시작 폭의 15%)로 올렸습니다.
- 탑 폭이 시작 폭의 25%보다 좁을 때는 '딱' 판정이 나오지 않도록 했습니다.

화면 구성, 등급 관련 콘텐츠, 광고·결제, 권한 등은 바뀌지 않았습니다.
