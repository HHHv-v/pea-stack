# 출시 체크리스트 · 완두콩의 높이 쌓기

코드로 할 수 있는 일은 끝냈어요. 아래는 계정·서명·심사처럼 **하니님이 직접 하셔야 하는 일**이에요.
순서대로 하면 돼요. 체크박스는 끝낸 것부터 표시해 두세요.

---

## 0. 준비 (10분)

- [ ] Node.js 24 이상 설치 (`node -v`로 확인). 앱인토스 개발 도구가 24 이상을 요구해요.
- [ ] 레포를 받아서 설치하고 실행해 보기
  ```bash
  git clone https://github.com/HHHv-v/pea-stack && cd pea-stack
  npm install
  npm run dev        # 브라우저에서 열고, 오른쪽 아래 AIT 버튼으로 토스 기능 흉내
  ```
- [ ] 직접 몇 판 해보고 손맛 확인. 난이도 숫자는 `src/game/engine.ts`의 `TUNING` 한 곳에 모여 있어요.
  시뮬레이션 기준 예상: 처음 하는 사람 약 13층, 보통 약 17층, 잘하는 사람 약 25층.

## 1. 앱인토스 콘솔에 게임 등록

콘솔: https://apps-in-toss.toss.im

- [ ] 워크스페이스 만들기 (개인으로 시작 가능)
- [ ] **게임** 미니앱으로 새 앱 등록 (비게임으로 등록하면 나중에 게임 카테고리로 다시 등록해야 해요)
- [ ] **appName: `pea-stack`** — 한 번 정하면 바꿀 수 없고, `apps-in-toss.config.ts`와 같아야 업로드돼요.
- [ ] 앱 이름(한글): `완두콩의 높이 쌓기`
- [ ] 영문 이름(15자 이내): `Pea Stack` (제안)
- [ ] 이미지 올리기 — 모두 `store/` 폴더에 규격대로 만들어 뒀어요
  | 항목 | 파일 | 규격 |
  |---|---|---|
  | 앱 로고 | `store/logo-600x600.png` | 600×600 PNG, 배경 있음, 각진 모서리 |
  | 게임 썸네일 | `store/thumbnail-1932x828.png` | 1932×828 PNG |
  | 세로 스크린샷 | `store/screenshot-1~5-*.png` | 636×1048 PNG, 5장(최소 3장) |
  > 로고·썸네일은 `npm run dev` 후 `/tools/brand.html`에서 다시 만들 수 있어요. 직접 그린 그림으로 바꾸셔도 좋아요.
- [ ] 부제·설명·검색어 입력 (아래 초안을 고쳐서 쓰세요. 부제에는 느낌표를 쓸 수 없어요)
- [ ] 고객문의 이메일 입력
- [ ] 카테고리: 캐주얼/아케이드 계열에서 고르기
- [ ] **리더보드 설정**: 점수 단위 `층`, 높을수록 위. 게임이 끝날 때 점수를 자동으로 보내요.

### 등록 문구 초안

- **부제**: `꾹 눌러 키우고 딱 맞춰 쌓는 완두콩 탑`
- **설명**:
  > 화면을 꾹 누르면 막대가 자라요. 아래층과 같은 폭이 됐을 때 손을 떼면 "딱!" 하고 쌓여요.
  > 틀린 만큼 탑이 좁아지니 신중하게! 누르는 동안 소리가 점점 높아지는데, 딱 맞는 순간의 음은 늘 같아요. 귀로도 맞출 수 있어요.
  > 파란 하늘에서 시작해 노을을 지나 우주까지, 완두콩을 높이 올려 보내 보세요.
  > 매일 바뀌는 오늘의 도전, 연속 출석, 친구와 겨루는 순위표가 있어요.
- **검색어**: 쌓기, 탑 쌓기, 타워, 블록, 완두콩, 타이밍, 캐주얼, 한 손 게임

## 2. 게임 등급분류 (게임은 등급 없이는 출시 불가)

두 가지 중 **하나**만 하면 돼요.

### A. 원스토어 경로 (무료, 빠름) — 추천

> ⚠️ 원스토어 **"웹 게임 / AI 게임"** 으로 받은 등급은 앱인토스 검수에서 반려된 사례가 있어요.
> 반드시 **일반 안드로이드 앱(APK)** 으로 올려야 해요. 그래서 `android/` 프로젝트를 만들어 뒀어요.

1. [ ] Android Studio 설치 (https://developer.android.com/studio)
2. [ ] APK 만들기
   ```bash
   npm run android        # 웹 빌드 → 안드로이드에 복사 → Android Studio 열기
   ```
   - Android Studio에서 **Build → Generate Signed App Bundle / APK → APK**
   - 서명 키(keystore)를 새로 만들고 **비밀번호와 파일을 안전한 곳에 백업**하세요. 잃어버리면 같은 앱으로 업데이트할 수 없어요.
   - 키 파일은 레포에 커밋되지 않도록 `.gitignore`에 넣어 뒀어요.
   - 결과물: `android/app/release/app-release.apk`
3. [ ] 원스토어 개발자센터 가입 (https://dev.onestore.co.kr, 개인 무료)
4. [ ] 새 앱 등록 → **게임** → APK 업로드 → 무료 앱
5. [ ] 등급: **앱 > 등급 > 등급 받기 > 새 IARC 인증서 요청** → 설문 작성
   - 폭력·공포·선정·약물·사행성·채팅·위치·구매 모두 "없음" → 보통 전체이용가가 나와요.
6. [ ] 심사 통과 후 하루쯤 지나 게임물관리위원회 "자체등급분류 게임물 조회"에서 확인
   - 안 보이면 날짜 필터를 **스토어 승인일** 기준으로 바꿔 보세요.
7. [ ] 앱인토스 콘솔 → 게임 등급분류에 입력
   - 스토어 URL, 등록자명, 자체등급분류사업자명(`원스토어`), 등급분류일자·번호, 이용등급, 내용정보
   - 대표자 인감 또는 사인 이미지
   - 플레이 화면: 원스토어 게임 2장 + 앱인토스 게임 2장 (같은 게임임을 보여주는 용도)
   - ⚠️ **원스토어 등록자명과 앱인토스 명의가 같아야** 해요. 다르면 반려돼요.

### B. 게임물관리위원회 직접 신청 (코드 작업 없음, 느림)

- [ ] https://www.grac.or.kr → 등급분류신청 → 오픈마켓/등급분류 신청
- 플랫폼 `모바일 게임`, 스토어명 `기타-앱인토스`, 네트워크 `인터넷 접속`
- 심의 10~15일, 수수료 있음. 받은 증명서 PDF를 콘솔에 첨부
- 주요 화면을 확정한 뒤 신청해야 해요(심의받은 화면과 출시 화면이 같아야 함)

## 3. 보상형 광고 연결 (수익)

1. [ ] 콘솔 → 수익화 → 인앱 광고 → **보상형(리워드) 광고 그룹** 만들기
2. [ ] 발급된 광고 그룹 ID를 `.env`에 넣기
   ```bash
   cp .env.example .env
   # .env 파일에 VITE_REWARDED_AD_GROUP_ID=발급받은ID
   ```
   - ID가 없으면 출시 빌드에서 "광고 보고 이어하기" 버튼이 숨겨져요(광고 없이도 게임은 정상 작동).
   - ⚠️ 문서 예시의 테스트 광고 ID를 그대로 출시하면 검수에서 반려돼요.
3. [ ] 사업자 등록: 광고 수익 **누적 5천 원까지는 사업자 없이** 운영돼요. 수익 알림이 오면 바로 등록을 시작하세요.
   5천 원 도달 후 5영업일 안에 승인이 안 되면 노출이 잠시 멈춰요(쌓인 정산금은 유지).

## 4. 빌드하고 올리기

```bash
npm run build      # dist/ 빌드 + pea-stack.ait 생성
```

- [ ] 콘솔에 `pea-stack.ait` 업로드 (또는 `npx ait token add`로 API 키 등록 후 `npm run deploy`)
- [ ] 콘솔 QR로 **토스 앱에서 직접 테스트** — 아래 검수 항목을 하나씩 확인

### 토스 앱 테스트 체크리스트 (검수 기준)

| 확인할 것 | 어떻게 |
|---|---|
| 10초 안에 첫 화면이 열린다 | 처음 진입 |
| 무음 모드·진동 끔에서도 이상 없다 | 휴대폰 설정 바꿔서 한 판 |
| 소리 켜기/끄기 버튼이 동작한다 | 왼쪽 위 스피커 버튼 |
| 홈으로 나갔다 오면 소리가 멈췄다가 다시 난다 | 플레이 중 홈 → 복귀 |
| 오른쪽 위 ✕ 버튼으로 나갈 수 있다 | 토스 상단 버튼 |
| 안드로이드 뒤로가기 → "게임을 그만할까요?" 확인창 | 뒤로가기 |
| 위쪽 버튼이 노치·다이내믹 아일랜드에 가리지 않는다 | 아이폰에서 확인 |
| 진동이 상황마다 다르게 온다 | 딱 맞춤 / 넘침 / 게임 오버 |
| 앱을 껐다 켜도 최고 기록·연속 출석이 남아 있다 | 종료 후 재진입 |
| 광고 보고 이어하기 → 끝까지 보면 이어진다, 중간에 닫으면 안 이어진다 | 결과 화면 |
| 광고가 끝나면 게임으로 돌아오고 소리가 다시 난다 | 결과 화면 |
| 순위 보기, 기록 공유하기가 열린다 | 결과 화면 |
| 광고 보고 코인 2배 → 끝까지 보면 코인이 늘어난다 | 결과 화면 |
| 꾸미기에서 산 콩·소품이 앱을 껐다 켜도 남아 있다 | 꾸미기 |

- [ ] 문제없으면 **검수 요청** (앱 정보·번들 검수를 한 번에 받을 수 있어요)

## 참고: 코드에 반영한 검수 기준

| 기준 | 반영 위치 |
|---|---|
| 소리 On/Off | `App.tsx` 스피커 버튼 |
| 백그라운드 전환 시 소리 즉시 정지, 복귀 시 재개 | `App.tsx` visibilitychange, `sound.ts` suspend/resume |
| 종료 시 확인 모달 | `App.tsx` + `toss.ts` onBack(backEvent) |
| 사용자 식별자 확인·저장 후 시작 | `toss.ts` getUserKey → 사용자별 기록 |
| 데이터 유지 | `toss.ts` Storage (토스 저장소) |
| Safe Area, 토스 ✕ 버튼 침범 안 함 | 상단 버튼 왼쪽 배치, `--safe-top` |
| 광고 미리 로딩, 예상 가능한 시점에만 | `toss.ts` preloadRewardedAd, 결과 화면 버튼에서만 |
| 광고 중 소리 정지 | `App.tsx` revive |
| 리워드 끝까지 시청 시에만 보상 | `toss.ts` userEarnedReward 확인 |
| 진입 즉시 바텀시트 없음, 자사 앱 유도 없음 | 해당 기능 없음 |
| 세로 고정, 풀스크린 | `toss.ts` lockPortrait, 캔버스 전체 화면 |
| 확률형 아이템 없음 | 꾸미기는 코인으로 바로 구매 |
