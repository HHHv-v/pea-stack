## 2026-11-18 (v5.1): 토스 앱에서 화면이 늘어나고 게임이 안 보이던 문제

- **증상**: 토스 앱에서 시작 화면의 해·구름이 세로로 길게 늘어나고, 쌓기 시작을 누르면 콩·층·화분이 하나도 안 보였어요.
- **원인**: 게임 엔진이 처음 만들어질 때 한 번만 캔버스 크기를 쟀어요(`resize()`). 토스 웹뷰에서는 이때 CSS가 아직
  적용되지 않아 캔버스 기본 크기 300×150이 잡혔고, 그 뒤로 창 크기 변화(`window resize`)가 없어서 다시 재지 않았어요.
  - 300×150으로 그린 그림을 393×852 화면에 늘려서 해·구름이 세로로 약 5.7배 늘어났어요.
  - 엔진은 화면 높이를 150px로 알고 있어서, 카메라가 맨 위층을 365px 위치로 올리는 계산 때문에 층과 콩이 전부 화면 밖으로 밀렸어요.
  - 빌드된 `index.html`에서 CSS `<link>`가 게임 스크립트보다 뒤에 있어서, 웹뷰에 따라 스크립트가 먼저 실행될 수 있어요.
    v5 코드의 문제라기보다 원래 있던 타이밍 문제가 이번에 드러난 것으로 봐요.
- **수정** (`engine.ts`, `main.tsx`)
  - `ResizeObserver`로 캔버스 크기가 바뀔 때마다 다시 재요. 매 프레임에도 실제 크기와 다르면 다시 재는 안전장치를 넣었어요.
  - 크기가 0이면 건너뛰고, 크기가 같으면 아무것도 안 해요. 시작 전에는 바뀐 폭에 맞춰 받침 폭도 다시 정해요.
  - `main.tsx`에서 CSS를 앱보다 먼저 불러와요.
- **확인**: 헤드리스 크롬에서 CSS를 1.5초 늦게 적용해 재현했어요. 고치기 전에는 캔버스가 600×300(300×150 × 2배)으로 굳어
  토스 스크린샷과 똑같은 화면이 나왔고, 고친 뒤에는 786×1704로 맞춰져 해·구름·화분·층이 정상으로 보여요.
